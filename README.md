**🕹️ Script Merger** — Automatic script conflict resolver for Witcher 3 mods. Script Merger detects and resolves script conflicts between Witcher 3 mods automatically. It merges conflicting script files intelligently, letting multiple mods that edit the same scripts coexist without manual patching.

## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Auto Merging** | Detects conflicting scripts and merges them automatically |
| **Diff Preview** | Visual side-by-side diff for every detected conflict |
| **Manual Resolution** | Override any automated merge with a built-in text editor |
| **Batch Processing** | Merge hundreds of script conflicts across a full mod list at once |
